version: 0.23.0
## A fresh look for Settings
- Every Preferences screen now has a colored icon next to each setting, the way macOS System Settings does.
- The About tab is rebuilt as cards: check for updates and a toggle for automatic updates, report a bug or request a feature, and jump to What's New.
- The Preferences sidebar now uses real Liquid Glass.

## See what's new
- KRIT shows a What's New panel after each update, so you never miss a feature.

## Notifications at a glance
- On-screen toasts (saved, copied, recording, errors) now carry a matching colored icon.
